# Brave, Equip and world-map labels — 0.1.52

This local build fixes the four reported menu screenshots and the matching shared text categories. It is based on frozen local 0.1.51. No GitHub release is authorized for this build.

Both resident atlas copies now contain 31 English labels: combat and radar stats, Normal/Special/Accessory tabs, Menu, HP modifier, PP cost, Owned, Assist Effect, None, Front/Back and related battle/field labels. The existing palettes, native group records, UVs, image dimensions, counters and icons are retained. Lettering is fitted into each original cell with a dark one-pixel outline. Rendering uses the established 4x rasterization step before quantization into the native atlas; these shared bitmap cells retain their native dimensions.

The compact stat legend is ATK = Attack, DEF = Defense, CHR/Charm = Charm, Link = Coordination, ACC = Accuracy, Crit = Critical, OBS = Observation and Field FX = Field Effect. The existing HP modifier crop is also used by the game's PP modifier composition. Move power, hit count, numerical values and effects are unchanged.

All 99 entries in the native move/weapon-name table and all 31 entries in the world-map location table are English. The map uses the existing glossary and translated location banners, including Forest of Unity. Modified Crack Enforce and Bent Sword address the reported Brave rows. Long names use explicit menu display forms; full previously established names remain recorded with the preparation evidence. The incantation labels retain their distinguishing spell titles rather than overflowing the single row. New ordinary weapon/technique names are descriptive translations; no official English localization is claimed.

Unequip, None, Front/Back, item/category controls and the three adjacent move/equipment help labels are translated. Four Bond Stone display names omit the item-type word Stone: Attack Bond, Charm Bond, Accuracy Bond and Critical Bond. Their measured widths are 78, 79, 95 and 83 native pixels, within the 103-pixel narrow list region. This display choice also applies to headings using the same name pointer. Full canonical names remain in the earlier translation data; inventory IDs, icons and item effects are preserved.

Preparation uses `tools/prepare_menu_labels_052.py`. Selected source string storage and ten obsolete source strings are reused only after checks exclude current, interior and code-pair owners. The executable has the same size, loaded memory extents, relocation records, font packet, VWF hooks and dialogue code as 0.1.51. Three load bases verify every changed pointer and all other loaded memory. `tools/append_cpk.py` replaces the two resident resources; `tools/build_menu_labels_052.ps1 -Write` creates the versioned ISO through the current local builder. Preparation is deterministic and its writer requires a fresh output directory and reviewed executable hash.

`tools/verify_menu_labels_052.py` checks the complete installed names, alias padding, widths, both atlases, regenerated title asset and their nested ISO bytes. The other 5,183 archive entries are unchanged relative to 0.1.51. Evidence lives in `work/ui/menu/0.1.52/`; images there include before/after native atlases and an actual startup frame.

Final readback passes all 139 changed typed strings and four accessory aliases. A fresh isolated ISO boot verifies the same complete strings in loaded memory and the actual 0.1.52 title stamp above the credit. The reviewed RGB5551 title crop has mean channel error 1.963 and maximum 9 against the generated preview. The final ISO SHA-256 is `43718e99569384f6945938890464a6bf550cfd052dad1d12a8d344c5c52e5950`.

Natural Brave, Equip and world-map playback remains unverified. The copied test save is from early Episode 1, before those menu features are enabled. The user's save is only read and copied into an isolated emulator. No custom names, save files, dialogue layouts, tail anchors or public release assets are changed.
