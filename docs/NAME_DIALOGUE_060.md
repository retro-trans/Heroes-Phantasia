The reported Shinobu thought in `phase/bin/p101070.bin` and `p101071.bin`, reference 9, belongs to an owner that inserts the player's surname on an earlier page. The installed VWF width pass rejects that substitution before committing any row widths. Every page then retains the native 13-pixel glyph-count measurement, including the later plain English page. The old guard excluded these owners instead of modeling that fallback. Their oversized shared width could make fitted geometry decline while the text retained the large native origin.

The new guard models that policy across the whole owner. Native selector buffers at offsets 0x37E4, 0x37EE, 0x3800 and 0x381A permit up to 9, 17, 25 and 15 single-byte characters respectively, excluding the terminator. These are conservative bounds for CP932 input as well. It checks every possible 13-pixel shared width between the literal minimum and maximum expansion, all pages, and all nonzero authored XY keys. It preserves custom input, name selectors, ruby attached to other base words, and nonlayout control order.
