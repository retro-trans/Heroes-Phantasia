# Compact battle special-move label — 0.1.26

The reported Japanese label beside the battle AP gauge uses executable table0/index54, not a baked battle-atlas word. Its original file offset is `0x94d92`, source RVA `0x94cd2`, pointer slot `0x94838`, and typed R_MIPS_32 ordinal 13519. A separate full-term source at `0x2ed390` already points to English Special Move and is outside this patch. Another occurrence is part of a longer configuration description; it remains outside this HUD fix.

The glossary term is **Special Move**. This compact HUD displays **Special**. The unchanged native caller constructs an 80px plate with the text beginning 25px from its left edge, leaving 55px. The inherited generic ASCII cursor adds float-LUT advances directly, independently of the nominal Japanese advance13. Its actual full-term advance is 86px; Special is 47px. The model made from the inherited 4x compressed glyph bank fits within the plate, with ink bounds `[25,0,72,16]`. The model is an illustration, not a native battle capture.

The patch relocates the complete eight-byte `Special` string, including NUL, into an excluded PNG tail and retargets its single typed pointer. It preserves the original Japanese source bytes, battle caller instructions, panel geometry, controls, global glyph widths, font bank and renderer hooks. No loaded memory growth or new relocation records are introduced. The font and all five PNG pointer/capacity/size triples remain verified; the other 25 gallery pointers and targets are exact.

Three actual section-loader models at different load bases verify the resulting pointer and all unrelated loaded bytes. The finished ISO's executable readback matches the reviewed patch exactly. Only the title resource's archive row changes from 0.1.25; all other 5,185 archive rows, including Forest of Encounters, are retained. The English HPMOVE03 prologue remains installed.
