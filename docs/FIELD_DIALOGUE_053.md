# Field dialogue, quest chapters and Kogoro — 0.1.53

This local build addresses the two overflowing HOLD soldier boxes, the remaining Japanese quest chapter heading and Kogoro's numeric speaker label in the reported screenshots. It carries forward frozen local 0.1.52. No GitHub release is authorized for this build.

The shared quest headers now read Chapter 1, Chapter 2 and Chapter 3. Their existing typed pointers use 30 previously unused bytes in the reviewed 0.1.52 text pool. Executable size, relocations, loaded extents, font and dialogue geometry code remain unchanged. Three load-base checks validate the pointers and every unaffected loaded byte.

The field audit checks all 300 indexed field-talk resources and 30 original resources containing Kogoro's numeric name. It identifies 95 records using native tailless styles. Twenty-two ordinary English records already fit and remain unchanged. Sixty-eight records require reflow or a larger authored tailless style. Both reported soldier boxes use the existing wider two-line style 132 at native position (122, 60); their maximum body advances are 174 and 198 pixels. No tail endpoint or portrait anchor changes: these field boxes have no tail.

New line breaks preserve all words. Style selection uses the widest existing one-, two- or three-line tailless template, and position keys are clamped into the native field viewport. White-interior checks use the maximum width across every page, matching the renderer's left-aligned text. All unrelated animation bytes, name selectors, unselected dialogue and resource suffixes are exact. One student message in `fld/talk/f502022.bin`, reference 2, needs an additional pause/page to fit; its four wrapped lines are divided evenly across two pages. Existing subsequent text and page order remain intact.
