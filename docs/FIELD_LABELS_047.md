# Field text without loaded-memory growth

Local build 0.1.47 installs the 28 shared Quest/Camp/Shop/map labels and 12 headquarters notices described in [FIELD_LABELS_046.md](FIELD_LABELS_046.md). It replaces the rejected 0.1.46 candidate, which passed static and loaded-string checks but remained on a black screen after system-data loading. The exact cause of that transition failure is unconfirmed; 0.1.46 must not be used as the test build.

The new composer leaves all three loaded program extents unchanged from 0.1.45. It stores the English text, exact notice keys and parser helper in original text regions whose native consumers already select relocated translations, plus the regions retired by these 28 new label replacements. It audits each retired menu string's unique typed R32 owner, including interior references. It also checks all 14 original HI/LO owners of the 1,280-byte notification bank against the installed replacement bank and verifies the active bank's complete digest. None of the active notification strings are overwritten.

The helper keeps the previous Episode 1 parser hook as its continuation. All source-authored event instructions, style selectors, triggers, branch timing and custom name selection remain unchanged. The long rank-bearing announcement adds one reviewed layout line break, retaining complete text. All 15 centered style-5 headquarters occurrences are covered, including both protagonists' elevator/Data Room notices; other event files are outside this scope.

All 28 label pointers use their existing R32 records. The helper adds 49 typed relocation records; the executable file grows by only 432 bytes for those records and the section header. Loaded memory grows by zero bytes, the original LOAD2 contents remain exact and the inherited memory forecast is unchanged. Three independent load-base models pass 1,044 actual emitted-instruction cases each. The font, default-name, bubble and prior parser helpers remain exact.

`tools/prepare_field_labels_047.py` is dry by default and requires the reviewed output hash for fresh writes. It uses the reviewed translations and cases from `prepare_field_labels_046.py`, then composes the installation independently on the frozen 0.1.45 executable. `tools/build_field_labels_047.ps1` supplies that executable to the authoritative local builder with the previous archive and English prologue. `tools/strip_jp.py` exports the 40 English-only records to `work/translation/en/field_labels_047.en.json`.

Current isolated startup passes the system-data load, opening movie transition, title and main menu; the 0.1.47 version/credit stamp is visually reviewed and its pixels match the prepared title. All 28 pointers and 12 complete notice keys/targets read back exactly from the loaded game. The nested ISO executable and title match, the original event resource is exact, and all 5,185 other archive rows are unchanged from 0.1.45. This includes the prior battle-label and location-banner work.

The separate read-only retired-storage audit examines 19,729 current typed references, including the previously installed helpers. The only remaining pointers into the proposed retired spans are precisely the 28 label owners retargeted here; no other inventoried typed reference uses the storage. There are 2,446 unrelated unresolved inventory records, so this is a relocation-derived scoped proof, not exhaustive arbitrary runtime pointer analysis.

Evidence is under `work/ui/field_labels/0.1.47` and `work/ui/title/0.1.47`. The shared check/verifier tools accept `--version 0.1.47`; the isolated debugger uses port 45404. Natural Quest/Camp/map placement and event-notice display remain separately unverified until current gameplay captures are available. No GitHub release is authorized for this local build.
